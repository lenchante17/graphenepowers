# Concept Options Brief Template

Use this during Stage 3 of `graphenepowers:brainstorming`.

The output should normally be saved to `docs/graphenepowers/specs/YYYY-MM-DD-<topic>-concept-brief.md`.

## Purpose

Give the user one document they can read once and then reply with their preferred options, approvals, or objections in one message.

## Suggested Structure

1. problem framing in one paragraph
2. recommended concept and why
3. option set
4. major structure and boundaries
5. choices the user should make now
6. deferred questions

## Option Rules

- lead with the recommended option
- keep each option concrete and meaningfully different
- include tradeoffs, not just descriptions
- make the reply surface obvious, for example: "Reply with A2, B1, and approve the recommended structure"
- do not force the user to reconstruct the option tree from scattered messages
